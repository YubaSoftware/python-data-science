# Python Data Science

A small, beginner-friendly space for learning Python and exploring data science step by step.

## Repository layout

```text
code/       Small, reusable Python examples
data/       Notes about storing project data
docs/       Short learning notes and guides
notebooks/  Exploratory notebooks
tests/      Tests for the Python examples
```

## Getting started

The starter example uses only the Python standard library:

```powershell
py -3 code\basic_statistics.py
```

Run its tests with:

```powershell
py -3 -m unittest discover -s tests
```

See [docs/data-basics.md](docs/data-basics.md) for a short introduction to working with data.
