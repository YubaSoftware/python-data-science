# Machine learning introduction

Machine learning uses examples to fit a model that can make predictions or describe patterns. It is not a substitute for understanding how data was collected or what a prediction means.

- **Supervised learning** learns from examples with a known target, such as predicting a numeric value (regression) or category (classification).
- **Unsupervised learning** looks for structure without a target, such as grouping similar observations.
- **Features** are input variables; the **target** is the outcome being predicted.
- A **train/test split** checks performance on examples not used to fit the model.

Begin with a clear question, a simple baseline, and an appropriate evaluation metric. Watch for data leakage, unrepresentative samples, and overfitting. This repository introduces the concepts only; model implementations can be added as a later learning unit.
