# Glossary

- **Analysis:** examining data to answer a question.
- **Categorical variable:** a value representing a group or label.
- **Correlation:** a measure of association between variables; it does not establish causation.
- **DataFrame:** a labeled, two-dimensional table commonly provided by pandas.
- **Dataset:** a collection of related observations.
- **Feature:** an input variable used in an analysis or model.
- **Missing value:** an absent or unavailable observation.
- **Observation:** one recorded case, often represented by a table row.
- **Outlier:** a value unusually distant from the rest under a chosen definition.
- **Population:** the full group a study aims to describe.
- **Sample:** a subset of a population.
- **Target:** the outcome a supervised learning model is asked to predict.
- **Vectorization:** applying an operation to an array or series as a whole instead of writing an explicit Python loop.
