# Data basics

Data is a collection of observations. A table stores observations in rows and their attributes in columns. For example, a temperature table might have one row per day and columns for the date and temperature.

Before analyzing a dataset:

1. Check what each row represents and what each column means.
2. Look for missing values, duplicates, and unexpected values.
3. Keep the original data unchanged; save cleaned results separately.
4. Summarize numeric columns with measures such as the mean and median.

The example in [`code/basic_statistics.py`](../code/basic_statistics.py) demonstrates the last step using a small list of temperatures.
