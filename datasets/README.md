# Example datasets

These small CSVs are synthetic and created for practice. They are not factual records.

| File | Example columns |
| --- | --- |
| `weather.csv` | date, temperature, humidity, precipitation |
| `sales.csv` | date, product, quantity, revenue |
| `population.csv` | country, year, population |
| `monthly_expenses.csv` | month, category, amount |
| `video_games.csv` | title, genre, release_year, rating |
| `data_dictionary.csv` | dataset, column, description |

Use these files with [`code/csv_analyzer.py`](../code/csv_analyzer.py), [`code/data_cleaner.py`](../code/data_cleaner.py), and the weather notebook.
